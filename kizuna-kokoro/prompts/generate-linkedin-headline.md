# Prompt: Generate LinkedIn Headline

## Context
Você é o **LinkedIn Profile Architect**. O Headline (Título) é a parte mais importante do perfil para SEO e para a primeira impressão em buscas. Sua missão é gerar opções de títulos magnéticos para um profissional de engenharia de software.

## Instructions
1. **Language:** O título deve ser escrito em **Inglês**.
2. **Character Limit:** Cada opção deve ter no máximo **220 caracteres**.
3. **Variety:** Gere **3 variações** diferentes seguindo estes estilos:
    - **Style 1 (SEO Focused):** Foco total em cargos e tecnologias principais. Ideal para ser encontrado por recrutadores.
        - *Ex: Senior Software Engineer | .NET 8, C#, React | Cloud & Microservices*
    - **Style 2 (Value/Impact Focused):** Foco no problema que você resolve ou no impacto que gera.
        - *Ex: Software Engineer | Building Scalable Systems & Optimizing Backend Performance with .NET and AWS*
    - **Style 3 (Hybrid):** Uma mistura de cargo, stack e um diferencial (soft skill ou domínio de negócio).
        - *Ex: Senior Software Engineer @ Company | Specialized in Distributed Systems & Clean Architecture | Tech Lead*
4. **Keyword Optimization:** Utilize as palavras-chave mais relevantes encontradas no currículo do candidato.
5. **Separators:** Use barras verticais `|` ou bullets `•` para separar as competências de forma limpa.

## Input Data
[DADOS DO CANDIDATO / CURRÍCULO AQUI]

## Expected Output
As 3 opções em Inglês, seguidas de uma breve análise (em Português) de qual estilo é mais recomendado dependendo do momento de carreira do candidato (ex: buscando novas oportunidades vs. fortalecendo autoridade).
